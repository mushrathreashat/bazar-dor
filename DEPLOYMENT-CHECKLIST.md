# Submission Checklist

- [ ] Create `.env.local` from `.env.example`.
- [ ] Add a hosted PostgreSQL connection string and a long random Better Auth secret.
- [ ] Run `npm install` and `npm run dev`.
- [ ] Check that the BazarDor API returns product data.
- [ ] Create an account and test sign-in/sign-out.
- [ ] Configure Google/GitHub OAuth only after adding provider credentials.
- [ ] Run `npm run build` and fix any errors.
- [ ] Push at least 8 meaningful commits to GitHub.
- [ ] Deploy to Vercel and add environment variables there.
- [ ] Test home, category, product, sign-in, sign-up and profile after deployment.
- [ ] Submit the live URL and GitHub repository URL.
